# Veri Seti Kurgusu
Bu proje kapsamında, bir hayvancılık işletmesindeki hava sıcaklığı ile günlük süt verimi arasındaki ilişkiyi analiz etmek amacıyla 500 satırlık sentetik bir veri seti üretilmiştir.

## Değişkenler:
- **Sicaklik (°C):** Ölçülen ortam sıcaklığını temsil eder. (Birim: Santigrat Derece)
- **Sut_Miktari (Litre):** Günlük elde edilen süt miktarını temsil eder. (Birim: Litre)

## Veri Yapısı:
Veriler, istatistiksel analizlere uygun olması açısından Normal Dağılım (Çan Eğrisi) formunda üretilmiştir. Bu sayede verilerin büyük çoğunluğu ortalama değerler etrafında toplanmış, uç değerler ise daha az sıklıkla yer almıştır.
